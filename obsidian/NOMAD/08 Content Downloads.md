# Content Downloads — Filling the Library

NOMAD starts **empty** — the offline superpowers only exist after downloading content *while the internet is still up*. Do this early. 1TB of disk = room for a lot.

## Where to do it

Command Center → **Easy Setup** wizard, or directly inside **Information Library** and **Maps**.

## Shopping list

- [ ] **Wikipedia** — options by size:
  - Simple English Wikipedia: ~1–2 GB (fastest, good starter)
  - Full English, no pictures: ~15–20 GB
  - Full English with pictures: ~100+ GB (the works — disk can take it)
- [ ] **Medical references** (Kiwix has WikiMed and first-aid packs) — the classic emergency use case
- [ ] **Maps: Jamaica** — plus anywhere else I care about
- [ ] **How-to / survival guides** (iFixit, WikiHow-style packs in Kiwix library)
- [ ] **Khan Academy** courses — big but gold for study
- [ ] **AI Chat** (Supply Depot → Ollama) — start with a small model (3B–8B) and see how the laptop handles it; bigger models need serious RAM

## Reminders

- Downloads continue only while the Ubuntu window stays open ([[03 Daily Routine — Start and Stop]])
- After downloading, test something with Wi-Fi OFF — that's the whole point ✈️
